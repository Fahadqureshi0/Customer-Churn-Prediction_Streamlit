# 👤 Customer Churn Prediction System

A Machine Learning web application that predicts whether a customer is likely to **Churn** or **Not Churn** based on customer information. The application is built using **Streamlit** and deployed on **Streamlit Community Cloud**.

## 🌐 Live Demo

https://customer-churn-predictionapp-bwistbukgzygynpdcvxdsc.streamlit.app/

---

## 📌 Features

- 👤 Predict whether a customer will churn
- ⚡ Real-time predictions
- 🖥️ Interactive Streamlit user interface
- 🤖 Machine Learning-powered prediction
- 🌐 Deployed on Streamlit Community Cloud

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Streamlit
- Pickle

---

## 🤖 Machine Learning Model

- Logistic Regression

---

## 📊 Input Features

- Age
- Gender
- Tenure
- Usage Frequency
- Support Calls
- Payment Delay
- Subscription Type
- Contract Length
- Total Spend
- Last Interaction

## ▶️ Run Locally

Clone the repository

```bash
git clone https://github.com/your-username/Customer-Churn-Prediction_Streamlit.git
```

Move to the project directory

```bash
cd Customer-Churn-Prediction_Streamlit
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run Customer_Churn_Prediction.py
```
